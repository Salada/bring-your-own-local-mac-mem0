# ADR 0003: Upgrade Mem0 OSS library to 2.0.20

- Status: Accepted
- Date: 2026-09-11

## Context

The runtime pinned `mem0ai[nlp]==2.0.19`. PyPI identifies 2.0.20 as the latest
non-yanked stable Python release, uploaded on 2026-09-02. The user explicitly
authorized this upgrade without applying the repository's normal seven-day
package-age hold.

Upstream describes two library changes: OSS notice evaluation now uses a static,
cacheable configuration with a bundled disabled fallback instead of a PostHog
feature-flag request, and Redis configuration uses Pydantic's native
`extra="forbid"` validation. Neither is a stored-memory schema migration.

The new notice implementation can fetch its static configuration from the Mem0
GitHub repository when telemetry is enabled. This runtime sets
`MEM0_TELEMETRY=False` before importing Mem0; an automated regression test
confirms that notice evaluation returns before that fetch, preserving the
existing no-telemetry network boundary.

## Decision

Pin `mem0ai[nlp]==2.0.20`, regenerate the `uv` lockfile, update the runtime's
reported baseline and version-bound documentation, and run the full local test
suite before deployment. Record a fixed package-specific uv cutoff of
`2026-09-03T00:00:00Z`; this admits the verified 2.0.20 artifacts without
relaxing the project-level rolling seven-day cutoff for any transitive
dependency or admitting a future Mem0 release implicitly. Declare both cutoffs
in `runtime/pyproject.toml` so fresh clones retain the same policy; uv records
the rolling `P7D` span in `uv.lock`.

Keep `runtime/gemini_http.py`. Source inspection of the 2.0.20 Gemini config and
adapter confirms that upstream still supports `vertexai`, `project`, and
`location`, but not the required Google Gen AI `base_url` or `http_headers`
client options. The compatibility provider therefore remains necessary and is
not an obsolete monkey patch.

## Consequences

No database, Qdrant collection, history, category, or temporal backfill is
required. The deployed host process must be restarted after the merged runtime
is installed so it imports 2.0.20. Normal backup and rollback procedures remain
available; the lockfile retains the exact artifact hashes.

This decision does not adopt Mem0's separate self-hosted server distribution or
its authentication model. The project continues to embed the Python library in
its loopback-only FastAPI adapter.
